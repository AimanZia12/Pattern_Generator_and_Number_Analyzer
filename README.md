
#This is a Python Program built for Pattern Generator and Number Analyzer-

A simple Python based project that allows users to select any one option among these three:

1. Pattern Generator.
2. Number Analyzer.
3. Exit the Program

##Features
This python program contains the following features-

1. Generating three different types of patterns-

Right-Angled Triangle
Pyramid
Left-Angled Triangle

2. Analyzing different range of numbers -

Analyze whether the inserted range of numbers are Even or Odd.
Sum of numbers present in the given range of numbers.

3. Exiting the program

Users can easily exit the program using the Exit option.

##Technologies Used
Python 3

##Working

As program starts, the user gets three options to select:

1. Pattern Generator
2. Number Analyzer
3. Exit

If user selected the 1 option that is Pattern Generator then user again gets three options to select

1. Right-Angled Triangle Pattern
2. Pyramid
3. Left-Angled Triangle Pattern 

Then user selects a pattern type and enters the number of rows to generate the pattern among the three options.

If user selected the 2 option that is Number Analyzer then user have to insert the starting number and ending number of a range .

Then the program perform two tasks-

1. Analyze each number of the range and displays whether it is Even or Odd
2. Calculates the sum of all numbers present in the range.

If user selected the 3 option that is to exits the program.

Then user came out of the program.

##Concepts Used-

This python project uses the following concepts:

1.while loops for the execution of the program.
2.if-elif-else conditions for defining several conditions.
3.Nested loops for defining the inner conditions.
4.User input handling for taking the input from the user for choosing among the tasks, patterns and for inserting the number of rows and and the starting and last number of a range.
5.Pattern printing for printing different patterns using print().
6.Range iteration is applied to analyze each number and can check whether it is even or odd.
7.Basic arithmetic operations is applied to find the sum of the numbers.
8.Program exit is done using break control statement.
